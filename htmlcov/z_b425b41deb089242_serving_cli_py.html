20class ServingCli: 

21 """Command line of what is served: promote an artifact a campaign kept, or withdraw a model. 

22 

23 Two invocations, on the machine that keeps the registry:: 

24 

25 uv run python -m emblema.entrypoints.cli.serving promote --checksum <checksum> 

26 

27 which prints the identifier of the model now serving it — the checksums are what 

28 ``campaign announce`` prints; ``--campaign <id>`` names the campaign where several kept the 

29 same artifact, and ``--candidate <name>`` the competitor where one campaign kept it as 

30 several — and:: 

31 

32 uv run python -m emblema.entrypoints.cli.serving withdraw --model <model id> 

33 

34 which takes that model out of service and prints its identifier again. 

35 

36 Standard output is the identifier and nothing else: whatever a library prints while a use 

37 case runs goes to standard error. 

38 """

41 WITHDRAW = "withdraw"
