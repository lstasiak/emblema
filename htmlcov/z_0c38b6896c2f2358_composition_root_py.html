26class CompositionRoot: 

27 """The process that runs an order of campaign cells where no registry and no queue reach. 

28 

29 Which candidates it carries is decided by the order, not by a flag: an order is one pool's 

30 cells, and the root that pool's worker is assembled from is assembled here too, over a 

31 registry of this run instead of the database and a queue that runs nothing. So a cell run 

32 through an order is answered by the very candidates a worker would answer it with. 

33 

34 Attributes: 

35 adapters: The port implementations the process runs on. 

36 services: The use case it runs. 

37 """
