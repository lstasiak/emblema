14@dataclass(frozen=True, kw_only=True) 

15class ServedModel: 

16 """An artifact promoted to answer requests: what this context serves. 

17 

18 Nothing is served that a finished campaign did not measure, and the model holds that by how 

19 it comes about: a new one is made by ``promoted`` out of a ``PromotableArtifact``, and the 

20 projection exists only for what a campaign announced it kept. The constructor is how a 

21 repository rebuilds a stored model, not a second way to make one. 

22 

23 Withdrawal is the one transition and it is final. A model taken out of service is not put 

24 back; promoting the same artifact again makes a new model, so that each period of service is 

25 one record with its own beginning and end. 

26 

27 Invariants: a model is not promoted before its campaign finished, and not withdrawn before 

28 it was promoted. 

29 

30 Attributes: 

31 served_model_id: Identity of the model. 

32 origin: The campaign, task and competitor its artifact was measured as. 

33 kind: What the candidate is made of, which decides what can run the artifact. 

34 artifact: The artifact served, by reference and checksum. 

35 promoted_at: When it was promoted. 

36 withdrawn_at: When it was withdrawn; ``None`` while it serves. 

37 """ 

38 

39 served_model_id: ServedModelId 

40 origin: ArtifactOrigin 

41 kind: CandidateKind

46 def __post_init__(self) -> None: 

47 if self.withdrawn_at is not None and self.withdrawn_at < self.promoted_at: 

48 raise InvalidServedModelError(

52 @classmethod 

53 def promoted( 

54 cls, kept: PromotableArtifact, *, served_model_id: ServedModelId, at: UtcDateTime 

55 ) -> Self: 

56 """A model serving what a finished campaign kept, from ``at`` on. 

57 

58 Raises: 

59 InvalidServedModelError: If ``at`` precedes the moment the campaign finished. 

60 """ 

61 if at < kept.completed_at: 

62 raise InvalidServedModelError( 

63 f"campaign {kept.origin.campaign} had not finished at {at.value.isoformat()}" 

64 ) 

65 return cls( 

66 served_model_id=served_model_id, 

67 origin=kept.origin, 

68 kind=kept.kind, 

69 artifact=kept.artifact, 

70 promoted_at=at, 

71 )

73 @property

78 

79 def withdraw(self, at: UtcDateTime) -> Self: 

80 """The model taken out of service at ``at``. 

81 

82 Raises: 

83 ServedModelWithdrawnError: If it was already withdrawn. 

84 InvalidServedModelError: If ``at`` precedes its promotion. 

85 """ 

86 if self.withdrawn_at is not None: 

87 raise ServedModelWithdrawnError( 

88 f"model {self.served_model_id} has already been withdrawn" 

89 ) 

90 return replace(self, withdrawn_at=at)
