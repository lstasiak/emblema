13@dataclass(frozen=True, kw_only=True) 

14class LabelSample: 

15 """The labelled windows one run is allowed to see, and what drew them. 

16 

17 A point on a label-efficiency curve is only a point if it can be drawn again: the task, the 

18 seed and the budget are carried with the windows so that the same run repeats and two methods 

19 compared at one budget are compared on the same labels. Two samples of equal size say nothing 

20 about each other unless they name the task they came out of. 

21 

22 Attributes: 

23 task: Task the windows were drawn from. 

24 windows: The drawn windows, in a fixed order. 

25 budget: What was asked for. 

26 seed: Seed the draw was made under. 

27 """ 

28 

29 task: TaskId 

30 windows: tuple[LabelledWindow, ...] 

31 budget: LabelBudget 

32 seed: int

34 @classmethod 

35 def drawn( 

36 cls, 

37 task: TaskId, 

38 pool: Sequence[LabelledWindow], 

39 budget: LabelBudget, 

40 bins: TargetBins, 

41 seed: int, 

42 ) -> Self: 

43 """Draw ``budget`` windows out of ``pool``, spread evenly over the strata of the target. 

44 

45 Each stratum is ordered by the rank its members' keys take under the seed, and the draw 

46 goes round the strata taking one at a time, so the budget spreads as evenly as the strata 

47 sizes allow and a stratum that runs out is simply skipped. Ranking each window on its own 

48 rather than shuffling the pool is what makes the draw independent of the order the windows 

49 arrived in, so it repeats on another machine and after a corpus grows. 

50 

51 A budget that takes the whole pool is not drawn at all: there is nothing to spread, and a 

52 task too small to fill its strata would otherwise be refused the one budget it can serve. 

53 

54 Raises: 

55 InvalidLabelBudgetError: If the pool holds fewer windows than the budget asks for. 

56 InvalidTargetBinsError: If a drawn budget leaves fewer windows than there are bins. 

57 """ 

58 wanted = budget.drawn_from(len(pool)) 

59 if wanted == len(pool): 

60 whole = cls._ordered(pool, range(len(pool))) 

61 return cls(task=task, windows=whole, budget=budget, seed=seed) 

62 strata = [ 

63 sorted( 

64 group, 

65 key=lambda index: seeded_rank( 

66 seed, pool[index].window.unit, pool[index].window.position 

67 ), 

68 ) 

69 for group in bins.of_pool(pool) 

70 ] 

71 rotation = sorted(range(len(strata)), key=lambda index: seeded_rank(seed, "stratum", index)) 

72 taken: list[int] = [] 

73 depth = 0 

74 while len(taken) < wanted: 

75 for stratum in rotation: 

76 if depth < len(strata[stratum]): 76 ↛ 75line 76 didn't jump to line 75 because the condition on line 76 was always true

77 taken.append(strata[stratum][depth]) 

78 if len(taken) == wanted: 

79 break 

80 depth += 1 

81 return cls(task=task, windows=cls._ordered(pool, taken), budget=budget, seed=seed)

91 

92 Summed in the sample's fixed order in double precision, so the value is the same on 

93 every machine and does not depend on where a run's arithmetic happens. 

94

97 """ 

98 if not self.windows:
