10@dataclass(frozen=True, kw_only=True) 

11class AdaptationPlan: 

12 """How one candidate is made out of the backbone for a task: mode, weights, schedule, seed. 

13 

14 One value holds everything a cell of the curve does to the backbone, so two cells can be told 

15 apart by comparing plans and a run reports the plan it was made under. Which weights it 

16 starts from is part of the plan rather than of the mode: the control arm starts from none, 

17 and every other mode from the artifact of a pretrained backbone, held by reference and 

18 checksum as the registry holds it. 

19 

20 Invariants: weights are named exactly when the mode starts from pretrained ones; low-rank 

21 updates are specified exactly when the mode adds them. 

22 

23 Attributes: 

24 mode: What the backbone's weights do while the task is learnt. 

25 backbone: Artifact of the pretrained weights the run starts from; ``None`` for the 

26 control arm. 

27 schedule: How long the task is learnt, in how large a step, under what decay. 

28 lora: The low-rank updates, where the mode adds them; ``None`` otherwise. 

29 seed: Seed of everything the run draws: the head, fresh backbone weights, the low-rank 

30 updates, the order of windows. Apart from the seed of the draw and outside the 

31 schedule: another seed is a repeat of the same schedule over the same labels. 

32 """ 

33 

34 mode: TransferMode 

35 backbone: ArtifactRef | None 

36 schedule: AdaptationSchedule 

37 lora: LoraSpec | None 

38 seed: int

60 def parameters(self) -> dict[str, str | int | float]: 

61 """The plan flattened to scalars, in a fixed order, for whoever reports a run. 

62 

63 Absent parts are rendered as empty text and zeros rather than left out, so every plan 

64 renders the same columns and two plans can be compared by comparing this mapping. The 

65 seed is named ``run_seed``, so a row that also carries the seed of the draw reads 

66 unambiguously. 

67 """ 

68 return { 

69 "mode": str(self.mode), 

70 "backbone": "" if self.backbone is None else self.backbone.key, 

71 "run_seed": self.seed, 

72 "epochs": self.schedule.epochs, 

73 "min_steps": self.schedule.min_steps, 

74 "batch_size": self.schedule.batch_size, 

75 "learning_rate": float(self.schedule.learning_rate), 

76 "weight_decay": float(self.schedule.weight_decay), 

77 "warmup_fraction": float(self.schedule.warmup_fraction), 

78 "final_lr_fraction": float(self.schedule.final_lr_fraction), 

79 "lora_rank": 0 if self.lora is None else self.lora.rank,
