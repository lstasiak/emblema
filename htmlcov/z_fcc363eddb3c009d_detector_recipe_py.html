11@dataclass(frozen=True, kw_only=True) 

12class DetectorRecipe: 

13 """How a detector is made: what it reads a window as, and how it scores one from the rest. 

14 

15 A detector is fitted on the windows of a task's fitting side without a label. One that reads 

16 features scores a window by its mean distance to the nearest fitted windows, every feature 

17 standardised over the fitting side; one that asks the pretext scores it by the error of what 

18 is filled in where a backbone's masks hide its cells. Its alarm is set where a stated share 

19 of the fitting windows, each scored as the rest are, would be flagged, so the score a run 

20 answers is the score above that alarm: positive is an alarm, and the alarm is set without a 

21 label. The score may first be read against the window's own unit, the alarm then set over 

22 the fitting windows read so. 

23 

24 Invariants: an encoder is read exactly when the features are an encoder's states; a 

25 backbone's masks are named exactly when the pretext is asked; neighbours are named, at least 

26 one, exactly when a distance is the score; the contamination lies strictly between zero and 

27 one. 

28 

29 Attributes: 

30 features: What a window is read as. 

31 reading: The encoder the states come from and how they are pooled, for features that 

32 are an encoder's; ``None`` for the summaries. 

33 neighbours: How many nearest fitted windows a score is the mean distance to; ``None`` 

34 where the score is an error. 

35 contamination: The share of fitting windows the alarm is set to flag. 

36 seed: Seed of the fit, which decides what an encoder at its initialisation draws. 

37 reference: What a window's score is read against before the alarm. 

38 pretext: Whose masks hide the cells, and how often, for a detector that asks the 

39 pretext; ``None`` otherwise. 

40 """ 

41 

42 features: DetectorFeatures 

43 reading: EncoderReading | None 

44 neighbours: int | None 

45 contamination: float 

46 seed: int 

47 reference: ScoreReference = ScoreReference.FITTING_SIDE 

48 pretext: PretextAsking | None = None

51 if (self.reading is None) == self.features.reads_an_encoder: 

52 raise InvalidDetectorRecipeError(

57 else "names an encoder it does not read"

60 if (self.pretext is None) == self.features.asks_the_pretext: 

61 raise InvalidDetectorRecipeError( 

62 f"a detector over {self.features} " 

63 + ("names no masks" if self.pretext is None else "names masks it does not ask") 

64 ) 

65 if (self.neighbours is None) != self.features.asks_the_pretext: 

66 raise InvalidDetectorRecipeError( 

67 f"a detector over {self.features} " 

68 + ("names no neighbours" if self.neighbours is None else "reads no neighbours") 

69 ) 

70 if self.neighbours is not None and self.neighbours < 1: 

71 raise InvalidDetectorRecipeError( 

72 f"a score is the distance to at least one neighbour, got {self.neighbours}" 

73 ) 

74 if not (isfinite(self.contamination) and 0.0 < self.contamination < 1.0): 

75 raise InvalidDetectorRecipeError( 

76 f"the contamination lies strictly between zero and one, got {self.contamination}" 

77 )
