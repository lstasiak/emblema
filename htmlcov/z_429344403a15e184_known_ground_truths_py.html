7class KnownGroundTruths: 

8 """The corpora a process can read the answers of, and where each one reads them from. 

9 

10 Which corpora those are is a fact about the deployment rather than about any adapter: the 

11 answers of one are counted from run-to-failure records on disk and of another read from a 

12 file published beside it, and a process that has neither can still run a campaign over a 

13 corpus whose answers it does have. A register rather than a table read from configuration, 

14 because a corpus named in an environment file could be pointed at the wrong reader and the 

15 task would be answered instead of refused. Where each corpus's files sit under the directory 

16 the process was given is part of the same fact, so a reader is bound to the directory its 

17 marker file is found in rather than to one an operator would have to know. 

18 

19 Only the turbofans are here. The other corpora are published without answers this context 

20 knows how to read, and a task defined over one of them is refused by name rather than 

21 answered by whichever reader happened to be registered first. 

22 """ 

23 

24 CMAPSS = "cmapss" 

25 TURBOFAN_MARKER = "train_FD001.txt" 

26 

27 @classmethod 

28 def under(cls, corpora: Path) -> CorpusGroundTruths: 

29 """Every corpus this process can answer for, reading from the raw corpora in ``corpora``.""" 

30 return CorpusGroundTruths({cls.CMAPSS: CmapssGroundTruth(cls.turbofans_under(corpora))}) 

31 

32 @classmethod 

33 def turbofans_under(cls, corpora: Path) -> Path: 

34 """Where the run-to-failure records sit, wherever the archive put them. 

35 

36 A corpus that was never fetched resolves to where it would have been, so what fails is 

37 the reading of a named file rather than the assembling of the process: a worker serving 

38 campaigns over another corpus has no business stopping because this one is absent. 

39 """ 

40 root = corpora / cls.CMAPSS 

41 found = sorted(root.rglob(cls.TURBOFAN_MARKER)) if root.is_dir() else [] 

42 return found[0].parent if found else root
