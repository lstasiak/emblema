24@dataclass(frozen=True, kw_only=True) 

25class EncoderSetting: 

26 """How a cell runs the encoder beyond its weights: what it drops, what it is given, its build. 

27 

28 The arm's rather than the schedule's, because the schedule is shared by every network of a 

29 campaign, the patch model included, which drops by its own specification; a dropout set on 

30 the schedule would be one some networks read and others ignore. The standard setting is the 

31 one every campaign ran under before these were knobs: nothing dropped, the raw readings, the 

32 backbone's shape and its linear value. 

33 

34 A grid lays the readings on equal steps, as the patch model and MiniRocket see them, and 

35 hands the encoder one token per channel and step from the channel's first reading on, 

36 carrying its last reading forward. The encoder is then the same network fed the gridded 

37 readings, so a comparison with the standard setting measures the grid and nothing else. 

38 

39 The value's embedding and the shape change what the encoder is built as, so they hold only 

40 for an encoder trained from no weights; the plan refuses them elsewhere. A variant turns the 

41 shape's four counts one knob at a time, so a setting may hold some of them while it is being 

42 turned; ``shape`` is the whole of them or nothing, and a plan takes only a whole one. 

43 

44 A clip bounds every token's value at the encoder's input, in the standard deviations the 

45 readings are standardised in, and leaves the gap alone. It changes what the encoder is fed, 

46 not what it is built as, so any encoder takes it, pretrained ones included; a published 

47 network fed the same tokens lost most of its lead to the readings beyond five standard 

48 deviations once its value embedding could pass them. 

49 

50 The layer read chooses which of the encoder's layers the head reads; it changes neither the 

51 encoder nor what it is fed. Reading below the last layer leaves the blocks above it out of 

52 what a run could train, so the plan takes it only where the encoder's weights do not train. 

53 

54 Invariants: the dropout lies in ``[0, 1)``; a grid has a positive, finite resolution; every 

55 count of the shape stated is positive; a clip is positive and finite. 

56 

57 Attributes: 

58 dropout: Share of activations the encoder drops while it learns the task. 

59 grid_resolution: Steps of the grid per unit of the corpus's time; ``None`` for the raw 

60 readings. 

61 value_embedding: How a token's value and gap reach the width. 

62 width: The encoder's own width; ``None`` for its backbone's. 

63 heads: The encoder's own heads per block; ``None`` for its backbone's. 

64 layers: The encoder's own number of blocks; ``None`` for its backbone's. 

65 feedforward_width: The encoder's own feed-forward width; ``None`` for its backbone's. 

66 value_clip: Bound on a token's value at the input, either side of zero; ``None`` for the 

67 readings as they are. 

68 layer: Which of the encoder's layers the head reads. 

69 """

151 def tuned(self, knob: str, value: str) -> Self: 

152 """This setting with ``knob`` turned to ``value``. 

153 

154 The dropout, the grid's resolution and the clip are read as numbers, the shape's counts 

155 as whole numbers, the value's embedding and the layer read by their names: a knob left at 

156 ``None`` has no value to take its type from. 

157 

158 Raises: 

159 UnknownKnobError: If the setting has no such knob, or it cannot take that value. 

160 """ 

161 if knob not in self.KNOBS: 

162 raise UnknownKnobError(f"an encoder has no knob {knob!r}; it turns {self.KNOBS}") 

163 try: 

164 match knob: 

165 case "value_embedding": 

166 return replace(self, value_embedding=ValueEmbedding(value)) 

167 case "width": 

168 return replace(self, width=int(value)) 

169 case "heads": 

170 return replace(self, heads=int(value)) 

171 case "layers": 

172 return replace(self, layers=int(value)) 

173 case "feedforward_width": 

174 return replace(self, feedforward_width=int(value)) 

175 case "grid_resolution": 

176 return replace(self, grid_resolution=float(value)) 

177 case "value_clip": 

178 return replace(self, value_clip=float(value)) 

179 case "layer": 

180 return replace(self, layer=LayerReading.of(value)) 

181 case _: 

182 return replace(self, dropout=float(value)) 

183 except (InvalidEncoderSettingError, ValueError) as error: 

184 raise UnknownKnobError(f"{knob} cannot be {value}: {error}") from error
